One razor-sharp excuse for skipping a pointless meeting, written by a small deterministic Python program. The program writes exactly one line to `/output/entry.txt`:

> Sorry, can't attend — my calendar read the agenda, recognized it as an email in a costume, and reported it to HR for impersonating work.

## Run it

```sh
python3 main.py
```

No dependencies, no network, no randomness — the same line every run.
